# 小说编辑润色工具

给创意写作者用的五步编辑流程工具。服务对象是已经有自己文字风格的作者——公众号写手、短篇小说作者——目标是**在不丢掉作者声音的前提下，把初稿推到能发表的程度**。

## 五步流程

```
① 语病与用词    逐句检查语病、通顺度、用词准确性，不动情节和结构
       ↓        停下来，作者逐条决定接受哪些
② 结构分析      行文脉络、读者吸引力、五个创作要素、对照参考作家
       ↓
③ 多结局分支    生成 2-3 个不同走向的版本，在"想说什么"层面不同
       ↓        停下来，作者选定一个方向
④ 定稿          可选分支、可保留原结局、可混搭
       ↓
⑤ 五位读者反馈  追更读者/文学评论者/同行写手/挑剔读者/目标受众
```

两个停顿关口是刻意设计的：第③步的分支必须建立在作者已确认的文字上，第⑤步的读者必须读作者真正选定的那一版。

## 三种用法

| 方式 | 怎么用 | 适合 |
|---|---|---|
| **网页版** | 打开 [在线地址](https://19858168025jj-collab.github.io/CC_text/)，填入 DeepSeek API Key | 想要点按钮式界面 |
| **通用提示词** | 复制 [PROMPT.md](PROMPT.md) 粘到任意 AI 对话框 | 手上有 DeepSeek / ChatGPT / 豆包等任意一个 AI |
| **Claude Skill** | 安装 `.claude/skills/novel-polish/` | Claude 用户，最省事 |

三种方式流程完全一致，选顺手的就行。

## 网页版说明

纯静态页面，把仓库下载下来双击 `index.html` 也能直接用，不需要装任何东西。

- **支持上传** `.txt` `.md` `.docx` `.pdf`
- **API Key 只存在你自己的浏览器里**（localStorage），不经过任何服务器
- 所有文本处理在浏览器本地完成
- 模型可在 `deepseek-v4-flash`（快、便宜）和 `deepseek-v4-pro`（质量更高）之间切换

DeepSeek API Key 在 https://platform.deepseek.com/api_keys 申请。

## 设计上的几个取舍

**为什么强调"不要改成通用文字"**——一篇有个人风格的稿子，如果被改得流畅、规范、四平八稳，那它就死了，哪怕每一句都"更通顺"。短句、重复、口语、朴素表达通常是作者的节奏和声音，不是错误。判断标准是"读者会不会卡住"，不是"是否符合规范书面语"。

**为什么参考作家要学方法而不是外观**——以默认的袁哲生为例：他的克制之所以有力量，是底下压着极大的情感压力，节制让这股压力找不到正门出去，最后从一个不相干的细节里漏出来。只学"句子短、不明说情绪"这些外观，写出来是空的。

**为什么五位读者要吵架**——如果五个人一致夸奖，这步就白做了。同一段留白，追更读者觉得没劲，文学评论者可能觉得正是全篇最好的地方。这种分歧才是作者真正需要的信息：这里没有"改对"的方案，只有"你想要哪一批读者"的取舍。
