# 通用版：让任何 AI 工具都能用这套流程

这个文件夹里的 **`AGENTS.md`** 就是完整的五步润色流程。它是纯文字的，不依赖任何特定的 AI。

`AGENTS.md` 是目前多数 AI 编程/助手工具都认的通用格式，**多数情况下你只要把这个文件复制到你放小说稿的文件夹里就行**，工具会自动读它。

## 对照表

先找到你用的工具，按"文件名"那一列命名，放到"位置"那一列的地方：

| 你用的工具 | 文件名 | 放在哪 |
|---|---|---|
| **Codex**（OpenAI） | `AGENTS.md` | 稿子所在文件夹 |
| **Cursor** | `AGENTS.md` | 稿子所在文件夹 |
| **Zed** | `AGENTS.md` | 稿子所在文件夹 |

| **GitHub Copilot** | `copilot-instructions.md` | `.github/` 文件夹里 |
| **Windsurf** | `.windsurfrules` | 稿子所在文件夹 |

**改名就是唯一要做的事**，文件内容一个字都不用动。

## 用法

放好文件之后，在那个文件夹里打开你的 AI 工具，直接说：

> 帮我看看 我的小说.txt

它就会自动按五步流程走：先查语病 → 等你确认 → 结构分析 → 生成不同结局的版本 → 等你选 → 五位读者反馈。

## 如果你的工具不在上面这张表里

两种办法：

1. **查一下你的工具读哪个文件**——搜索"你的工具名 + AGENTS.md"或"自定义指令"，把 `AGENTS.md` 改成对应的名字就行
2. **直接用聊天版**——上一层目录的 [`PROMPT.md`](../PROMPT.md) 是同一套流程的对话版，复制粘贴到任何 AI 的聊天框里都能用（DeepSeek、ChatGPT、豆包、Kimi……），不需要工具支持任何格式

## 这套流程是什么

```
① 语病与用词    逐句检查，不动情节和结构
       ↓        停下来，你逐条决定接受哪些
② 结构分析      行文脉络、读者吸引力、五个创作要素、对照参考作家
       ↓
③ 多结局分支    2-3 个不同走向的版本
       ↓        停下来，你选定一个方向
④ 定稿          可选分支、可保留原结局、可混搭
       ↓
⑤ 五位读者反馈  追更读者/文学评论者/同行写手/挑剔读者/目标受众
```

核心不是"让 AI 改文章"，而是**用五个不同的视角把一篇稿子看透**，所有决定还是你自己做。两个停顿关口就是为了保证这一点。

流程里最强调的一条是**不要把作者的声音改成通用文字**——短句、重复、口语、朴素表达通常是你的节奏和声音，不是错误。
